## Checklist dei criteri di rientro

Dentro i tempi minimi e le restrizioni del protocollo medico; i valori sono quelli della Parte L (esempio ginocchio), da adattare con l'équipe.

:::grid
| Fase | Criterio | Raggiunto (data) | Firmato da |
| --- | --- | --- | --- |
| 1 → 2 | Versamento in traccia; flessione > 130°; estensione attiva simmetrica; cammino di 30' senza dolore né zoppia | | |
| 2 → 3 | Squat monopodalico ripetuto ~90" a ≥ 45°; Quad Index > 70%; Y-balance anteriore < 8 cm; plank laterale > 90" | | |
| 3 → 4 | Quad Index e indice ischio > 90%; Y-balance < 4 cm | | |
| 4 → 5 | Hop test (singolo, triplo, 6 m, crossover) > 90%; T-test < 10% di differenza | | |
| 5 → gara | Forza ≥ 90% anche rispetto al pre-infortunio; COD pianificati e non pianificati senza dolore; carico di allenamento completo tollerato; test psicologici (paura di rilesione) | | |
| Sempre | Risposta a 24 ore: dolore e gonfiore tornano al basale | | |
:::

## Il promemoria in una pagina

:::operativo Da tenere a mente
**Prima di tutto**: screening. Segnali d'allarme → medico, non programma. Il protocollo del fisioterapista/chirurgo ha la priorità.

**I tre input**: chi (atleta), per cosa (sport), quando (calendario). Se ne manca uno è un template.

**Si costruisce all'indietro**: gara → taper → realizzazione → trasmutazione → accumulo → oggi.

**Prestazione = fitness − fatica.** Il taper funziona perché la fatica decade prima. Si testa da scarichi.

**I residui comandano la sequenza**: aerobico e forza max presto, mantenuti con poco (~30 gg); velocità e potenza vicino alla gara e toccate ogni settimana (~5 gg).

**Un obiettivo dominante per mesociclo.** Scarico ogni 3-6 settimane: stesso carico, metà serie.

**Taper**: volume −40/60%, intensità mantenuta, frequenza conservata, 1-3 settimane, riduzione progressiva.

**Dosi base**: forza ≥ 85%, 1-6 rip, 2-5' · ipertrofia 67-85%, 6-12 rip, 30-90" · potenza 30-60% balistici / 80-90% forza, 1-5 rip, 2-5' · resistenza ≤ 67%, ≥ 12 rip, ≤ 30".

**Pliometria**: prima l'atterraggio; contatti come carico (principiante 60-100); 48-72 h tra sedute; recupero 1:5-1:10.

**Intervalli**: fosfageni 1:12-1:20 · glicolitico 1:3-1:5 · aerobico 1:1-1:3. Cambiare il work:rest cambia l'obiettivo.

**Giovani**: maturazione e competenza, non età. 2-4 × 6-12 ≤ 80%, niente cedimento; pliometria 2/sett; 3:1; ore settimanali ≤ età.

**Nel microciclo**: priorità a SNC fresco, giorni alti e bassi, qualità in conflitto separate, il giorno dopo la gara è il più leggero. **In-season si mantiene.**

**Sostituzioni**: stesso pattern, stessa zona F-V, stessa contrazione, stesso bi/monolaterale. Si sostituisce l'esercizio, non si toglie il pattern. Ritarare i parametri.

**Rientro**: per criteri dentro i tempi minimi; regola delle 24 ore; forza e hop test ≥ 90%, anche rispetto al pre-infortunio.

**Correzioni**: una variabile per volta, una settimana per vedere l'effetto. Se si taglia, si taglia dall'accumulo, mai dal taper.

**Ciò che rende un piano un piano**: il criterio di uscita da ogni blocco, scritto prima di iniziarlo.
:::
