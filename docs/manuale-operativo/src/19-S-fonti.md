## Glossario

| Termine | Significato |
| --- | --- |
| **1RM** | Massimo carico sollevabile per una ripetizione |
| **ACWR** | Rapporto acuto:cronico: carico dell'ultima settimana / media delle ultime 4 |
| **AMRAP** | "Più ripetizioni possibili" nell'ultima serie, con tecnica pulita |
| **Accumulo / trasmutazione / realizzazione** | I tre blocchi della periodizzazione a blocchi (Issurin): base → capacità speciali → espressione in gara |
| **Biobanding** | Raggruppare i giovani per maturità invece che per età |
| **CKC / OKC** | Catena cinetica chiusa (piede fisso, es. squat) / aperta (es. leg extension) |
| **CMJ** | Salto con contromovimento |
| **COD** | Cambio di direzione su percorso noto (≠ agilità reattiva) |
| **DAE** | Defibrillatore automatico esterno |
| **Deload** | Settimana di scarico per consolidare |
| **DOMS** | Indolenzimento muscolare ritardato (12-72 h) |
| **DUP / WUP** | Periodizzazione ondulata giornaliera / settimanale |
| **FCmax / FCR** | Frequenza cardiaca massima / di riserva (Karvonen) |
| **HIIT / SIT** | Intervalli ad alta intensità / sprint interval training |
| **HRV** | Variabilità della frequenza cardiaca |
| **LSI** | Indice di simmetria tra arti |
| **MD** | Match day: giorno della partita (MD−1 vigilia, MD+1 giorno dopo) |
| **Needs analysis** | Analisi delle richieste dello sport e dell'atleta |
| **PAP / PAPE** | Potenziamento dopo un'attivazione pesante (base del complex training) |
| **PHV** | Picco di velocità di crescita della statura |
| **RAMP** | Riscaldamento: Raise, Activate/Mobilise, Potentiate |
| **RED-S** | Carenza energetica relativa nello sport |
| **RFD** | Velocità di sviluppo della forza |
| **RIR / RPE** | Ripetizioni in riserva / sforzo percepito |
| **RSA** | Capacità di ripetere sprint |
| **RSI** | Indice di forza reattiva (altezza del salto / tempo di contatto) |
| **sRPE** | RPE della seduta × minuti (unità arbitrarie) |
| **SSC** | Ciclo stiramento-accorciamento |
| **SSG** | Giochi a campo ridotto |
| **Taper** | Riduzione del carico prima della gara |
| **TM** | Training max (~85-90% del 1RM) |
| **VAM / VIFT** | Velocità aerobica massima / velocità finale del 30-15 IFT |
| **VBT** | Allenamento basato sulla velocità del bilanciere |
| **WBGT** | Indice di stress termico (temperatura, umidità, irraggiamento, vento) |
