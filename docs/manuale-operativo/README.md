# Manuale operativo di preparazione fisica — Andrea Scirè

Manuale personale di consultazione che riunisce e aggiorna la *Guida alla periodizzazione* e la
*Guida alle sostituzioni* e le integra con tutti gli argomenti della base di conoscenza di scienze
motorie (valutazione, forza, pliometria, velocità, condizionamento e corsa, giovani, popolazioni
speciali, prevenzione, rientro, sport specifici, banca dati, piani svolti, griglie).

- `Manuale-operativo-preparazione-fisica.pdf` — il manuale.
- `src/*.md` — i contenuti, una parte per file (A-R).
- `build.py`, `style.css`, `cover.html`, `figures.py` — generatore (stesso design delle guide precedenti).

Rigenerare: `pip install weasyprint markdown && python3 build.py`
