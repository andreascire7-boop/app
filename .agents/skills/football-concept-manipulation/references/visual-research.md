## Research categories

Determine which of these a given concept actually needs — don't research categories that don't apply:

- **Player**: reference photographs — face, body, pose, current kit, boots, accessories
- **Kit**: the exact current/relevant jersey — shorts, socks, club crest, manufacturer, sponsor, competition patches, shirt details
- **Environment**: stadium, city, architecture, streets, landscapes, interiors, historical locations, cinematic environments
- **Objects**: trophies, footballs, vehicles, statues, buildings, props, symbolic objects — fictional/artistic props only where they serve the concept
- **Atmosphere**: smoke, fog, rain, dust, fire, sparks, particles, clouds, lightning, snow, water, haze
- **Lighting**: sunset, stadium lights, moonlight, dramatic backlight, volumetric light, practical lights, cinematic reference lighting
- **Textures**: stone, metal, concrete, grass, sand, glass, fabric, weathered surfaces, architectural textures
- **Reference images**: camera angle, perspective, composition, cinematic mood, color palette — not for copying, for understanding technique

## Research strategy

Every reference must have a purpose — never collect images "just in case." For a concept like *"footballer as Roman gladiator in a modern stadium"*, the research list looks like: player reference, exact kit reference, Colosseum/Roman architecture reference, gladiator visual reference, stadium reference, armor/material reference, night lighting reference, smoke/atmosphere reference, camera perspective reference — nine targeted items, then combine them into an original composition. Build a similarly short, purposeful list for each new concept instead of a generic one.

## Source quality and priority

Prefer, in order:
1. Official sources (club/league/federation media, official player accounts/press kits)
2. Reputable, high-resolution, clean image libraries and licensed stock
3. Public-domain or appropriately licensed imagery
4. Original/generated reference assets where appropriate

Avoid low-resolution, heavily compressed, or visibly altered images as final-asset sources — they degrade the composite and are harder to integrate convincingly.

## Watermark and licensing handling

If a useful reference carries a watermark:
- Do **not** remove, erase, crop around, or reconstruct the watermark.
- Search for an equivalent clean source first (official account, press kit, licensed library).
- If no clean source exists, use the image only as a **conceptual** reference (pose, lighting, composition idea) — never reproduce it as, or trace it into, the final asset.

Treat every third-party image the same way regarding rights: prefer sources you can reasonably use for editorial/fan-art purposes, and don't present a sourced image as an original generated asset or vice versa.
