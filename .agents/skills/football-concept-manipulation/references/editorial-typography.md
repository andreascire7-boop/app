# Editorial typography

## Contents
- When to add type
- Elements
- Treatment
- Hard rule

## When to add type

Only when the user requests it or the format clearly calls for it (e.g. a campaign/announcement graphic). A pure concept-art piece often works better with no type at all — don't add it by default.

## Elements

Choose only what's relevant: player name, competition, match/date, a statistic, a title, or a campaign statement. Don't stack all of them onto one graphic — editorial type should support the image, not compete with it.

## Treatment

- Establish a clear hierarchy (one dominant element, the rest secondary/supporting)
- Use an editorial grid — align type to the same structure as the composition, not floating arbitrarily
- Keep spacing controlled and consistent
- Stay restrained — typography should feel like a considered graphic-design layer, not a sticker on top of the artwork

## Hard rule

Never modify, replace, or add to text that's actually printed on the player's jersey (sponsor, name, number). Editorial typography is a separate graphic layer on top of the image, not an edit to the kit itself — see [football-kit-fidelity.md](football-kit-fidelity.md).
