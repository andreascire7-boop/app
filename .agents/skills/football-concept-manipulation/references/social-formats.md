## Format specs

| Platform / use | Aspect ratio |
|---|---|
| Instagram feed | 4:5 (portrait) |
| Instagram Story / Reel | 9:16 |
| TikTok | 9:16 |
| X (Twitter) | Landscape (~16:9) |
| Behance / portfolio presentation | Presentation-oriented — often a wide or multi-panel layout showing the full composition, sometimes with detail crops |

## Choosing a format

If the user specifies a format or platform, follow it exactly. If they don't, default to a strong editorial vertical composition (roughly 4:5) — it reads well across social platforms and suits hero-subject-driven football graphics — unless the concept clearly benefits from a wide cinematic frame (e.g. an environment-heavy establishing shot), in which case use landscape instead. Compose for the chosen format from the start rather than cropping afterward (see [composition.md](composition.md)).
